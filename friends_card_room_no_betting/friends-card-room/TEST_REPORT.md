## 실제 실행한 검사

1. `npm ci && npm test`: **97개 통과 / 실패 0 / 건너뜀 0**.
   - 기존 카드 판정, 초대/권한, 방 관리 및 HTTP 검사를 유지.
   - 2인 및 3~9인 블라인드/차례, 체크/콜/레이즈/폴드/올인 검사.
   - 짧은 올인과 누적 증액에 따른 레이즈 권한, 사이드 팟, 동률, 홀수 칩, 미콜 반환 검사.
   - 폴드한 카드/미공개 보드/승자의 비공개 카드가 상대 상태 및 기록에 노출되지 않는지 검사.
   - 허용되지 않은 금액은 상태를 바꾸지 않고 400, 지난 차례의 요청은 409로 거절.
   - **9개의 독립 HTTP 참가 세션**으로 방 생성/승인/준비/폴드/베팅/결과 검증.
   - 포함된 **시드 기반 무작위 1,000핸드**: 2~9인 종료와 칩 총량 보존, 음수/소수 스택 부재 검사.
2. `npm run test:exhaustive`: 52장 중 5장 **2,598,960개** 족보 분류 전수 검사 통과.
   - 하이 카드 1,302,540 / 원 페어 1,098,240 / 투 페어 123,552 / 트리플 54,912
   - 스트레이트 10,200 / 플러시 5,108 / 풀 하우스 3,744 / 포 카드 624 / 스트레이트 플러시 40
3. JavaScript 구문 검사: 서버·게임·홀덤·브라우저 스크립트.
4. 로컬 Chromium 화면/조작 검사:
   - 실제 HTML/CSS/JS를 로드하고, 테스트용 API 연결을 통해 로컬 Node 서버 상태와 연결.
   - 폴드 확인창, 레이즈 총액/추가액 표시, 콜/체크, 정산, 방장 설정, 전원 스택 무료 재설정 확인.
   - 가로 1365/1000/390px에서 가로 넘침 없음. 테스트 중 JS 페이지 오류 없음.

## 검사 방식의 한계

브라우저 관리 정책으로 직접 localhost URL을 여는 방식이 제한되어, DOM에 실제 화면을 로드하고 테스트용 API 연결을 사용하는 방식으로 조작했습니다. 이 연결은 검사 코드에만 있으며 배포되는 앱 코드에는 포함되지 않습니다. 서버의 HTTP 경로는 별도 테스트에서 실제 요청으로 검사했습니다.

**Render 실제 배포, 외부 휴대폰 사이 통신, 모든 모바일 기종, 장시간 부하, 복잡한 모든 베팅 순열에 대한 완전 검증은 하지 않았습니다.** 5장 족보의 전수 검사가 7장 모든 조합이나 포커 게임 전체의 완전 검증을 뜻하지 않습니다. 실서비스 보안 인증이나 금전 거래에 대한 검증이 아닙니다.

배포 후 별도 브라우저/기기 2개로 새 방을 만들어 한 핸드 진행을 먼저 확인하세요. 재배포 전 진행 중인 방을 끝내고 필요한 공개 결과를 저장하세요. 메모리 상태는 재시작하면 소실됩니다.
